Agentic-AI:
  These are tools written using python for agentic-AI opreations.
  
  lang/:
    Used for langchain AI orchestration frameworks.
    kubeagentlang.py:
      Tools used by agents using the langchain framework for kubernetes and a few docker opreations.
      
  mcp/:
    MCP for connecting different agents with differing orchestration frameworks to AI tools
    kubeagentmcp.py:
       Tools used by agents connected through MCP for kubernetes and a few docker opreations.
    naviagentmcp.py:
       Tools alloowing agents connected through mcp to access and read directories and files on PC.
       
  Run Command: python3 file.py
  
  For more guidance on requirements or dependencies go to: https://github.com/TrainWithShubham/agentic-ai-for-devops
